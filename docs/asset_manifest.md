# Asset Manifest

All runtime art is packed into WebP atlases in `assets/` and indexed by `js/manifest.js` (generated by `tools/build_assets.py`).
Character frames are normalised to a common scale; every frame stores a **bottom-centre foot pivot** (`ax`,`ay` = head-centre x, feet y), so all directions share one root point.
